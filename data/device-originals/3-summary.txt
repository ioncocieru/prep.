Introduction 
The IT Specialist certification, particularly in the Device Configuration and 
Management domain, validates the fundamental skills necessary for a successful 
career in information technology. Data management—from configuring cloud and 
local storage to correctly applying permissions and implementing backup 
strategies—is a cornerstone of an IT specialist's responsibilities. A thorough 
understanding of these concepts is not just a requirement for the exam but an 
absolute necessity for ensuring the integrity, security, and accessibility of data in a 
modern work environment. 
Section 1: Cloud Services and Storage Configuration 
(Objective 3.1) 
This section addresses the fundamentals of data storage, both in the cloud and on 
local devices. It analyzes the concepts, services, and configurations that enable 
efficient storage, sharing, and synchronization of information. 
1.1 Describing Cloud Services 
Fundamental Concepts of Cloud Storage and Collaboration 
Cloud Storage is a model for storing digital data on external servers that are 
managed, maintained, and secured by a third-party provider. This model transforms 
capital expenditures (CapEx), associated with purchasing and maintaining one's own 
data centers, into operational expenditures (OpEx), allowing organizations to pay 
only for the resources they use. 
Cloud service models define the level of management transferred to the provider: 
●​ Infrastructure as a Service (IaaS): The provider offers fundamental 
computing resources, such as virtual servers, storage, and networking. The 
client remains responsible for managing the operating system and 
applications. 
●​ Platform as a Service (PaaS): The provider offers a platform that allows 
clients to develop, run, and manage applications without the complexity of 
building and maintaining the associated infrastructure. 
●​ Software as a Service (SaaS): The provider offers complete software 
applications, accessible via the internet on a subscription basis. The client 
does not manage the underlying infrastructure or platform. 
These services can be implemented in various models, each with its own 
advantages: Public Cloud (shared, highly scalable resources), Private Cloud 
(infrastructure dedicated to a single organization, enhanced control), Hybrid Cloud 
(a combination of the two, offering flexibility), and Multicloud (using services from 
multiple public providers). 


 
Key benefits of cloud adoption include scalability (the ability to adjust resources on 
demand), flexibility in accessing data, advanced security provided by vendors, and 
redundancy, which ensures business continuity by replicating data across multiple 
locations. For collaboration, cloud tools offer essential functionalities like 
version control (tracking changes), centralized storage (a single source of truth for 
files), real-time communication, and custom permissions to control access to 
sensitive information. 
Identifying Common Cloud Service Providers 
In the IT ecosystem, certain providers dominate the cloud services market, and 
knowing their offerings is essential. 
●​ Microsoft Azure: This is Microsoft's IaaS and PaaS platform, offering a vast 
range of storage services. Among the most relevant are Azure Blobs for 
massive storage of unstructured data (images, documents), Azure Files for 
file shares accessible via standard protocols (SMB/NFS), and Azure 
Managed Disks, which function as block-level storage volumes for Azure 
virtual machines. 
●​ Microsoft 365 (M365): This is Microsoft's SaaS suite, an integrated package 
of applications and services designed for productivity and collaboration. Key 
components include: 
○​ SharePoint: A robust platform for creating intranet sites, document 
management, and team collaboration. It acts as a central repository for 
files shared within an organization. 
○​ OneDrive: The personal cloud storage service for each user, allowing 
for the storage, sharing, and synchronization of files across multiple 
devices. 
○​ Outlook and Teams: Fundamental tools for communication (email, 
chat, video meetings) that integrate natively with SharePoint and 
OneDrive for file sharing. 
○​ Windows 365: A "Cloud PC" service that provides users with a 
complete, virtualized Windows desktop, accessible from any device. 
This service uses persistent cloud storage, integrated with OneDrive, 
ensuring a consistent work experience between sessions. 
File Sharing Capabilities and Permissions in the Cloud 
Microsoft 365 platforms offer granular mechanisms for access control. In SharePoint 
and OneDrive, users can share files and folders with both colleagues within the 
organization and external users (guests). This can be done through direct invitations 
or by generating shareable links, which can be configured to allow only viewing or 
also editing of the content. In Microsoft Teams, although the sharing interface is 
simplified, the underlying storage mechanism is a SharePoint site. Each Team has 


 
an associated SharePoint site, and each channel has a dedicated folder in the site's 
document library. Therefore, permissions for files in Teams are essentially 
SharePoint permissions, and their advanced management is done in the SharePoint 
interface. 
Offline File Synchronization 
A major advantage of the M365 ecosystem is the ability to work with files even 
without an internet connection. The OneDrive sync client allows users to 
synchronize document libraries from SharePoint and their own OneDrive content to 
the local computer. Any changes made offline are saved locally and automatically 
synchronized to the cloud once the internet connection is restored. 
The Files On-Demand functionality is particularly important for managing local 
storage space. It allows viewing the entire cloud file structure in File Explorer without 
actually downloading every file. Files have different statuses, indicated by icons: 
●​ Online-only (blue cloud): The file is visible but does not take up disk space. 
It requires an internet connection to be opened. 
●​ Locally available (green circle with a checkmark): The file has been 
opened, downloaded locally, and is available offline. Space can be freed up by 
selecting the "Free up space" option. 
●​ Always keep on this device (solid green circle with a checkmark): The 
file is permanently downloaded to the device and is always available offline, 
taking up disk space. 
This tight integration between cloud services and local storage highlights a reality of 
the IT Specialist role: management is not limited to a single environment but to the 
interface between them. The ability to configure and troubleshoot synchronization, 
explain the Files On-Demand functionality to users, and ensure data consistency 
between the cloud and local devices is an essential skill that will likely be tested in 
practical scenarios during the exam. 
1.2 Describing and Configuring Local Storage 
Although cloud storage is ubiquitous, the correct configuration of local storage drives 
remains a fundamental task. 
Partitioning and Formatting a Disk Drive 
Before a new disk can store data, it must be prepared through a two-step process. 
Partitioning is the act of creating logical divisions on a physical disk. These 
divisions, or partitions, define the "boundaries" within which the operating system 
can work. 


 
Formatting, on the other hand, is the process of creating a file system (such as 
NTFS or exFAT) within a partition, organizing the space to store files and folders. In 
Windows, the graphical utility 
Disk Management (diskmgmt.msc) is the standard tool for these operations, allowing the 
creation of new volumes from unallocated space and formatting them with the 
desired file system.

Choosing the right combination of partition style and file system is a fundamental 
decision with long-term consequences. For example, an exam scenario might 
present a user with a new 4 TB external hard drive that needs to be used to store 
large video files and be compatible with both Windows and macOS. A correct 
analysis leads to the conclusion that the disk must be initialized with the GPT style to 
overcome the 2 TB limit of MBR. Subsequently, the partition must be formatted with 
exFAT, as NTFS would not allow native writing on macOS, and FAT32 would not 
support the large video files. 
Configuring File and Folder Attributes 
Windows associates each file and folder with a set of attributes that define its 
behavior: 
●​ Read-Only (R): Prevents accidental modification or deletion. 
●​ Hidden (H): Hides the item from standard view in File Explorer. 
●​ System (S): Marks a file as critical for the operating system. 


 
●​ Archive (A): Indicates if the file has been modified since the last backup, 
used by backup software.​
These attributes can be viewed and modified either through the graphical 
interface (right-click > Properties) or using the attrib command in Command 
Prompt. 
Effect on Permissions when Copying/Moving Data 
The behavior of permissions when transferring files depends on the source and 
destination file systems. The fundamental rule is that when copying or moving a file 
from an NTFS volume to a FAT32 or exFAT volume, all granular security 
permissions (Access Control Lists - ACLs) are lost. This happens because FAT file 
systems do not have the capability to store this security metadata. The copied file 
will inherit the simple permissions of the destination folder. Within NTFS volumes, 
the rules are different: when moving a file within the same volume, the original 
permissions are preserved; when copying within the same volume or copying/moving 
to another NTFS volume, the file inherits the permissions of the parent folder at the 
destination. 
Section 2: File Sharing and Permissions (Objective 3.2) 
This section details the mechanisms by which access to files and folders is 
controlled, both for local users and for those accessing resources over the network. 
2.1 Describing and Configuring Local and Network Permissions 
Share Permissions vs. NTFS Permissions 
In Windows, the security of shared file access is managed through a dual permission 
system, the understanding of which is vital for troubleshooting. 
●​ Share Permissions: These act as a first barrier and apply exclusively when a 
resource is accessed over the network. They have no effect for a user 
accessing the file directly on the local server. These permissions are less 
granular, offering only three levels: Read (view), Change (read, write, modify, 
delete), and Full Control (all actions, including changing share permissions). 
●​ NTFS Permissions: These are applied at the file system level and are valid 
for both local and network access. They offer much more detailed control, with 
permissions like Full Control, Modify, Read & Execute, List Folder 
Contents, Read, and Write, which can be combined to precisely define what 
actions a user can perform. 
Effective Permissions 
When a user attempts to access a file through a network share, both sets of 
permissions are evaluated. The fundamental rule, and probably the most important 


 
concept to remember for the exam, is that the most restrictive permission

This principle is the source of many common access problems. A technician might 
check the NTFS permissions and see that a user has "Full Control," but if the share 
permission is set to "Read," the user will not be able to modify the file. A good 
administrative practice is to set the share permission to "Full Control" for the 
"Authenticated Users" group and manage the actual access exclusively through 
more granular and secure NTFS permissions. To check a user's final permissions, 
the "Effective Access" tab in the "Advanced Security Settings" window of a file or 
folder can be used. 
Basic vs. Advanced Permissions 
The standard security interface in Windows presents "Basic" permissions, such as 
"Read" or "Modify." These are, in fact, predefined collections of "Advanced" 
permissions. For example, granting the basic "Read" permission to a user actually 
gives them the advanced permissions of "List Folder / Read Data," "Read Attributes," 
"Read Extended Attributes," and "Read Permissions." Advanced permissions offer 
extremely fine control, but in most cases, basic permissions are sufficient. 
Public, Basic, and Advanced Shares 
The terminology related to sharing can be confusing, but it refers to distinct 
concepts. 
●​ Network Profiles (Public vs. Private): This is an operating system-level 
setting that defines the behavior of the firewall and network visibility. A 
"Private" profile is for trusted networks (home, office) and enables features 
like network discovery, allowing other devices to see the computer. A 


 
"Public" profile is for untrusted networks (cafes, airports) and disables 
discovery to enhance security. A common file-sharing issue is an incorrectly 
set network profile to "Public" in an office environment, which makes the 
computer "invisible" to colleagues. 
●​ Sharing Methods (Basic vs. Advanced): 
○​ "Share..." (Basic Sharing): The button visible in the context menu, 
which offers a simplified interface. This method primarily adjusts NTFS 
permissions for the specified users and configures default share 
permissions in the background. 
○​ "Advanced Sharing...": This option provides direct and explicit control 
over Share Permissions, independent of NTFS permissions. It is the 
preferred method for administrators for precise control. 
Mapping Network Drives 
Mapping a network drive assigns a drive letter (e.g., Z:) to a network share, making it 
appear in "This PC" like a local drive. This simplifies access for users. Mapping can 
be done through: 
1.​ File Explorer: The simplest method, using the "Map Network Drive" graphical 
interface. 
2.​ Command Prompt: Using the command net use Z: \\server\share. 
3.​ PowerShell: Using the cmdlet New-PSDrive -Name "Z" -PSProvider FileSystem 
-Root "\\server\share" -Persist. 
Taking Ownership of Files or Folders 
The Owner of an object (file or folder) implicitly has the right to modify its 
permissions, regardless of other security settings. Taking ownership is an essential 
step in troubleshooting access issues, especially when an administrator needs to 
access the files of a former employee. The process is done from the "Advanced 
Security Settings" window, by clicking the "Change" link next to the owner's name 
and selecting the new owner (usually the administrator account). 
Section 3: Managing Backup and Restore (Objective 3.3) 
Protecting data against loss is a critical responsibility. This section covers backup 
and restore methods, from individual file versions to complete system images. 
3.1 Setting File Versioning/History 
The concept of File Versioning involves automatically saving multiple versions of a 
file as it is modified. Instead of overwriting the previous version, the system keeps a 
history of changes, allowing users to revert to a previous state in case of errors, 
accidental deletions, or unwanted changes. 


 
File History in Windows is the native tool that implements this concept for user 
files. It works by creating periodic copies of files from the user's libraries 
(Documents, Pictures, Music, etc.) to an external drive or a network location. 
●​ Configuration: It is enabled from Control Panel > File History, where the 
destination drive for the backup is selected. 
●​ Restoration: Users can browse through the file history using the dedicated 
interface, viewing and restoring specific versions of a file or folder to a 
previous date. 
3.2 Full Disk Backup and Restore 
It is essential to distinguish between file backup and system backup. While File 
History protects user data, a full disk backup (System Image Backup) creates an 
exact copy of the entire partition, including the operating system, installed 
applications, settings, and all files. This method is crucial for disaster scenarios, such 
as hard drive failure or a malware infection that corrupts the operating system, as it 
allows for the complete restoration of the computer to a functional state. 
●​ Full Disk Backup to the Cloud: Although Windows offers native tools for 
creating system images on local or network drives, modern solutions often 
rely on third-party cloud services. Platforms like IDrive Mirror or Dropbox 
Backup offer full machine backup functionalities to the cloud, often with 
additional benefits like incremental backups (which save only the modified 
data blocks) and ransomware protection. 
●​ Full Disk Restore from the Cloud: The process of restoring from a system 
image typically involves booting the computer from a recovery medium (e.g., a 
bootable USB) and using the backup software to write the saved image back 
onto a new or reformatted disk. The principle is illustrated by the​
 Point-in-Time Restore functionality in Windows 365, which allows an 
administrator to restore an entire Cloud PC to its exact state from a previous 
point in time. This process highlights both the benefits (quick recovery) and 
the risks, such as the loss of all data and changes made after the restore 
point was created. 
An IT specialist must clearly understand the difference between these two types of 
backup to recommend the correct solution. For a user who accidentally deleted a 
document, File History is the quick and appropriate solution. For a computer that no 
longer boots due to a system error, a restore from a system image is necessary. This 
distinction is a likely topic for exam questions based on troubleshooting scenarios. 
3.3 Restoring Previous Versions of Files 
In addition to the main File History interface, Windows integrates versioning 
functionality directly into File Explorer. By right-clicking on a file or folder and 
selecting "Properties," the "Previous Versions" tab will list the available copies saved 


 
by both File History and system restore points. From here, users can open, copy, or 
directly restore an older version of a file, providing a quick and convenient recovery 
method. 
Conclusions  
Mastering the "Data Access and Management" domain is fundamental to success in 
the IT Specialist: Device Configuration and Management certification exam. The 
analysis has revealed several cross-cutting concepts that are essential for 
demonstrating a deep understanding, beyond simply memorizing definitions. 
Synthesis of Key Points: 
1.​ Interaction of Permissions: The rule that the effective permission for 
network access is the most restrictive of the Share and NTFS permissions is 
a central pillar in troubleshooting file access issues. 
2.​ Fundamental Storage Decisions: The correct choice between MBR and 
GPT, and between NTFS, FAT32, and exFAT, is not a matter of preference but 
a technical decision with direct implications for capacity, security, and 
compatibility. Exam scenarios will test the ability to make the optimal choice 
based on specific requirements. 
3.​ Differentiating Backup Methods: It is crucial to distinguish between file-level 
backup (File History), which protects user data, and system-level backup 
(System Image), which protects the entire operating system. Each method 
addresses different disaster scenarios. 
4.​ Cloud-Local Integration: The modern role of an IT specialist involves 
managing a hybrid ecosystem. Skills related to offline synchronization, Files 
On-Demand, and ensuring data consistency between local devices and cloud 
services are indispensable.
